## 统一台词

现在 AI 产品太多了，每天都有新工具、新模型、新应用出现。普通用户很难判断：这个产品到底好不好用？适合什么场景？观猹想解决的，就是这个问题。TokenDance 词元跳动，是观猹生态旗下的一站式大模型 API 聚合平台。你专心做内容，商业的事猹与猹来。

## 生成与处理

`generate.py` 与 `生成记录.json` 保留模型路径、Python 环境、随机种子、完整音色描述、原始文件哈希和实际时长。为了明确发音，合成输入用“观茶”“茶与茶”对应“观猹”“猹与猹”，TokenDance 拆为 Token Dance，API 拆为 A P I；文稿保持原文。

原始干声 WAV 完整保留。试听 MP3 只做固定增益音量匹配，未变调、变速、添加音乐或混响。所有 MP3 完整解码检查结果见 `音频技术检查.json`。自动转写另记 `转写检查.json`，仅作漏字、重复和截断线索，主观音色与自然度待用户试听。

重新生成：使用 `生成记录.json` 中的 runtime 运行本目录 `generate.py`，已成功生成的条目会跳过；然后运行 `package.py` 输出试听文件。
