- 镜4｜航班屏上四个绿字"全 快 稳 省"；猹猹的想法气泡被装进行李箱，到达口取出来是一个产品界面｜全、快、稳、省。（字卡：让丰富的模型能力，成为每一个想法走向现实的起点）｜5 秒
- 镜5｜塔台：跑道堵了自动改道，多条跑道择优降落，一块大屏管所有航班；猹猹拿着两根荧光棒想指挥飞机，塔台已经调完，他把荧光棒当筷子假装吃东西｜如果你在企业里管模型调用：哪条跑道空走哪条，几家航司，一块屏管。更稳、更省、更省心。（画面：智能路由 · 多端点择优 · 统一管理；三指标）｜12 秒
- 镜6｜开发者猹开了一条新航线；猹妹用自己的里程钱包（TokenPay）换座位，值机、安检、登机三道口合成一个；开发者按真实乘客数拿收益，猹猹留言"座位太挤"，v2 换大飞机｜如果你是开发者，认识一下 TokenPay，Token 钱包：连起用户、模型和应用，授权、调用、计费，一步搞定。乘客用自己的里程来坐，你验证得快，每次真实调用，都是收益。好项目就这么长起来。（画面：原话逐条，里程 = Token 示意）｜18 秒

- 镜8｜停机坪上一架印着 CHA & CHA 的直升机启动，螺旋桨声压过来，直接进 10｜（无旁白，接猹与猹的转场）｜2 秒

和 r8 的关系：替换 06–09，并把 10 的直升机出场提前到这一段的结尾；D 的玩法里"D 是门"最配（航站楼的拱门）。

### 5｜地铁换乘站

一句话：六条地铁线是六种能力，TokenDance 是换乘枢纽，一张交通卡刷遍所有线；TokenPay 就是乘客自己的卡余额，实体卡就是联名交通卡。

适合：预算紧，一张线路图就能讲清；TokenPay 的"用户用自己的额度"要讲到最直白；实体卡的形态（联名交通卡）观众秒懂。

怎么做：

- 镜1｜两只顺着扶梯滑进漆黑的地铁站，站名牌只亮一个 T；一列 D 形的列车进站，车头拼上标识，全站灯亮｜这就是观猹生态的另一块拼图——TokenDance 词元跳动，一站式大模型 API 聚合平台。（标题含"观猹生态旗下"）｜9 秒
- 镜2｜线路图：六条线六种颜色，全部在这一站换乘；猹妹从开发者乱麻里抽出一张交通卡，一刷，所有闸机同时开｜一个 API Key，连接国内主流模型。（各线路运营方 = "国内主流模型"）｜6 秒
- 镜3｜六列车依次进站，车厢里装着一行字、一张图、一段视频、一条声波、图文、一个搜索地球｜文本、图像、视频、语音、多模态、联网搜索。｜5 秒
- 镜4｜站内四块标语牌"全 快 稳 省"（像真实地铁的口号）；猹猹的想法气泡上了车，下一站下车变成一个产品界面｜全、快、稳、省。（字卡：让丰富的模型能力，成为每一个想法走向现实的起点）｜5 秒
- 镜5｜调度中心：哪条线拥堵，乘客自动被引导到另一条，多条线并行，中控大屏管全网；猹猹在站台举着小旗要指挥乘客，广播已经引导完｜如果你在企业里管模型调用：哪条线空走哪条，几家线路，一块屏管。更稳、更省、更省心。（画面：智能路由 · 多端点择优 · 统一管理；三指标）｜12 秒
- 镜6｜开发者猹开通了一条新线"周一不慌线"；猹妹刷自己的卡余额进站（用户用自己的额度），进站、乘车、扣费三道合成一刷；开发者按真实客流拿收益，猹猹留言"班次太少"，v2 加密班次｜如果你是开发者，认识一下 TokenPay，Token 钱包：连起用户、模型和应用，授权、调用、计费，一步搞定。乘客刷自己的卡来坐，你验证得快，每次真实调用，都是收益。好项目就这么长起来。（画面：原话逐条，余额 = Token 示意）｜18 秒
- 镜7｜售卡机掉出一张联名交通卡，猹猹要咬；猹妹贴到平板上，猹猹画的火柴人变插画，联名吉祥物从车窗探出来击掌｜品牌方和用户，也有一份礼物：联名 Token 实体卡。那个，不能吃。算力装进卡里，送得出去，也玩得起来；用它探索 AI、做出自己的东西，品牌和用户，就在创造里连上了。｜16 秒
- 镜8｜出站口的扶梯升上去，就是城市夜景，楼顶有直升机的灯｜（无旁白，接 10）｜2 秒

## D 的玩法

TokenDance 标识里的 D，内侧两道斜线像一双眼睛。下面 6 种出场和贯穿方式，都要品牌方同意改动标识；每种写出场动作、之后在哪几段再出现、结尾怎么收。

### D1｜跳进来（r8 现行）

- 出场：漆黑大厅，标识只亮一个 T；画外"咚"一声，D 从右边跳进来，一跳一停，落地挤扁、弹起拉长，停在两只面前歪头看一眼，再一个大跳"咔"地拼到 T 旁边，整座工厂亮起。旁白正好念到"这就是观猹生态的另一块拼图"。
- 再出现：06 在六个厂区之间一格格跳，跳到哪个哪个亮；07 替猹猹先试拥堵的线路再跳到最顺的那条。
- 结尾：12 田垄上读到 TokenDance 时，标识里的 D 轻轻跳一下。
- 搭配：方案 0、1、3 都顺。
- 代价：拟人动画三处，约 8 秒无旁白；D 的性格要靠动作建立，没有台词。
- 标签：#我推荐

### D2｜D 是门

- 出场：标识的 D 是一扇拱门，两只从黑暗里摸到一道 D 形的光缝，推开，门后就是整座工厂城亮着；门框上的 T 和 D 合成标识。
- 再出现：07、08、09 三段各从一扇 D 形门进去，门上分别标"面向企业""面向开发者""面向品牌与用户"，三扇门并排，观众一眼看到三类用户。
- 结尾：12 的三个标识里，TokenDance 的 D 门缓缓关上，像一天结束。
- 搭配：方案 4 机场（航站楼拱门）、方案 0。
- 代价：最省，门是静态结构，不需要角色动画；但 D 没有性格，少了一个"角色"。
- 标签：#低制作成本

### D3｜D 是鼓手

- 出场：漆黑里先听到两道斜线敲出的节拍"哒、哒"，灯亮，D 站在鼓架后面，两道斜线是鼓棒；它敲一拍，标识亮一格，四拍拼完整座城亮起。
- 再出现：06 六种能力每一拍亮一个；07 请求按它的节拍通过；08 收益按它的节拍 +1；全片 06–09 的剪辑点都在它的鼓点上。
- 结尾：12 读到 TokenDance 时它敲最后一拍，三个标识定版。
- 搭配：方案 2 交响乐团最配，方案 0 的 DJ 台也行。
- 代价：需要音乐先定、画面跟音乐剪，制作顺序要调整；好处是"词元跳动"四个字被音乐坐实。
- 标签：#更逗

### D4｜D 是导游旗

- 出场：两只掉进工厂城，不知道往哪走；一面 D 形的小旗从人群里举起来，旗面写着"TokenDance"，它一摇，三条路亮起。
- 再出现：07 旗面翻成"企业团"，带两只进调度室；08 翻成"开发者团"；09 翻成"品牌与用户团"。三个"面向"变成三次跟团，旁白的"如果你是……"正好对上。
- 结尾：12 旗子收起，D 回到标识里，鞠一躬。
- 搭配：所有方案；对"三类用户"的结构最清楚。
- 代价：旗子要做三次翻面动画；旅游团的感觉会让这一段偏轻，企业段要靠画面上的术语撑住专业感。
- 标签：#低制作成本

### D5｜D 是钥匙柄

- 出场："一个 API Key"那一刻，猹妹从乱麻里抽出的钥匙，钥匙柄就是 D 的形状；插进去一转，T 和 D 咬合成标识，整座城亮起。拼图和钥匙两句话一起讲完。
- 再出现：07 钥匙转一下，调度室的门开；08 转一下，TokenPay 的三道门合成一个；09 转一下，联名卡从锁孔里滑出来。每段开头同一个动作，观众会等它。
- 结尾：12 钥匙从田垄的标识里拔出来，D 回到标识上。
- 搭配：方案 1 总闸最配（总闸钥匙），方案 0 也顺。
- 代价：钥匙的三次转动是同一个动画，复用成本低；D 没有自己的动作性格，更像道具。
- 标签：#低制作成本 #我推荐

### D6｜D 是拼图块

- 出场：甲方原文说"另一块拼图"，就真的做成拼图：06 开场，观猹的"猹"图标是第一块拼图悬在空中，缺一角；D 从天而降，严丝合缝拼上去，两块一合，工厂城亮起。
- 再出现：06–09 里 D 不再单独表演，拼图悬在每个场景的背景里，提醒"这是生态的一部分"；10 猹与猹出现时，第三块拼图从直升机上吊下来。
- 结尾：12 三块拼图在田垄上拼成一张完整的图，三个标识各占一块，"把创造这条路铺完整"的字卡正好落在拼缝上。
- 搭配：所有方案；对结尾"三个品牌是一个生态"的表达最强。
- 代价：三块拼图的形状要专门设计，三家标识都要改动，需要三方同意；D 作为角色的戏少了，换来的是结构感。
- 标签：#更正式
