# 13｜视觉方向与色彩脚本

这份文件是视觉决策的备选库：三个画风方向的深度比较、r8 十二段的色彩脚本、字幕和信息卡的三套样式候选、开工前要先做的视觉资产清单。全部是提案，用来在 10/13 画风确认前挑选和删减，不是定稿。编号 V01–V16 对应 `视觉开发/全风格整合-r1/阅读说明与编号.md`；角色外观以 `资产/角色/` 的两张官方锚定图为准。

## 一、三个画风方向的深度比较

先说前提：用户已排除透明和油亮效果（R01 亮釉瓷感、R02 磨砂玻璃已退出；R03–R05 需去反光后再考虑）。下面只比较还在桌上的三个方向。

### 方向 A｜干净 3D 系列（V13 极简哑光、V14 自然光简洁、V16 深绿布光）

| 项目 | 说明 |
| --- | --- |
| 优点 | 背景和道具最少，注意力全在角色；哑光材质没有反光问题；三张图本身就是同一套角色在不同布光下的样子，说明这个方向天然适合"一套角色、三种布光"的分段策略；V13 的浅灰底、V14 的窗光、V16 的深绿底刚好能对应观猹（浅、暖）、TokenDance（深、冷）、猹与猹（黑绿）三段 |
| 缺点 | 场景感弱，瓜田、工厂城、摩天楼这些需要"大场面"的镜头要另外建立场景语言；角色少了官方平面图的粗线条，第一眼不如平面风"像官方" |
| AI 生成的一致性风险 | 低。简洁 3D 是生成模型最熟悉的风格，圆形体积和纯色材质最不容易在镜头之间漂移；主要风险在猹妹的头发和帽子细节（刘海、低马尾、熊耳帽的耳朵位置），需要固定一段角色描述反复使用 |
| 和官方 IP 的还原度 | 中到高。五官（小圆眼、小鼻子、微笑嘴）、绿 T 恤、大尾巴、熊耳帽、腮红都能一比一照搬；差别只在线条，官方是粗描边平面，这里是体积。V13 这张图里猹妹的刘海和低马尾已经很接近锚定图 |
| 字幕和信息卡适配 | 最好。底色干净、对比柔和，白字黑边字幕和绿底信息卡放上去不打架；大字砸下来时背景不抢 |
| 三段业务怎么区分 | 不换画风，只换布光和配色：观猹段用 V14 的自然窗光和暖色；TokenDance 段用深色底加青绿霓虹，接近 V16 的思路但底色改成近黑；猹与猹段直接用 V16 的深绿布光加轮廓光 |
| 推荐度 | ★★★★★。制作周期 4 天、62 个镜头、要叠大量文字，这个方向风险最低、最能保证前后统一 |

### 方向 B｜漫画电影式 3D（V05 为代表，V06 手绘质感 3D 相近）

| 项目 | 说明 |
| --- | --- |
| 优点 | 最有"电影感"和画面张力，暖光、景深、网点阴影让单帧很好看；工厂、调度室这种机械感场景在这个风格里最出彩（V05 原图就是插头和发光模块）；适合做海报和封面 |
| 缺点 | 画面信息量大，细节多、对比强，和字幕、信息卡、界面抢眼；网点和笔触在视频生成里容易闪烁；V05 里猹妹的头发是蓬松长发，和官方锚定图的刘海加低马尾有距离，需要专门校正 |
| AI 生成的一致性风险 | 中到高。风格本身依赖高细节，镜头之间的光线、网点密度、笔触粗细很难稳定；角色一旦转到不同光线下，面部比例容易变 |
| 和官方 IP 的还原度 | 中。五官能保留，但整体气质偏"动画电影角色"而不是"表情包 IP"；官方的平面粗线条感基本消失 |
| 字幕和信息卡适配 | 弱。需要给文字加底板或暗角才能读清，信息卡数量一多就乱 |
| 三段业务怎么区分 | 靠场景和色温：瓜田金色暖光、工厂青色冷光、总部黑绿。能区分，但每段的细节量都很大，4 天内很难全部做到同样完成度 |
| 推荐度 | ★★☆☆☆ 作为全片主风格；★★★★☆ 作为"海报和开场 1 张定场图"的风格。建议只用它做宣传物料，不用它跑 62 个镜头 |

### 方向 C｜贴近官方的平面风（V01 手绘卡通、V04 清爽赛璐璐为主；V02 二维动画场景、V03 印刷网点漫画为辅）

| 项目 | 说明 |
| --- | --- |
| 优点 | 和官方锚定图几乎是同一种语言，"尽量还原官方 IP 形象"这条 brief 要求在这个方向最容易满足；甲方看第一眼不会问"这是我们的猹吗"；平面图的表情（吃西瓜、惊讶、兴奋、疑惑）可以直接套用锚定图里的表情表 |
| 缺点 | 平面风的"动"最难：AI 视频生成对粗描边角色的线条稳定性最差，容易抖、糊、描边断裂；大场面（瓜田俯拉、工厂城、航拍摩天楼）在平面风里要靠画面设计撑，不如 3D 自带空间感；直升机、DJ 台、摩天楼这些"气场"镜头在平面风里容易显得幼 |
| AI 生成的一致性风险 | 高（动态）/ 低（静帧）。如果大量镜头用静帧加推拉，平面风完全可行；如果要生成真正的角色动作视频，描边风险最大 |
| 和官方 IP 的还原度 | 最高 |
| 字幕和信息卡适配 | 好。平面底色干净，文字容易读；但信息卡本身也是平面图形，要靠颜色和位置和画面区分 |
| 三段业务怎么区分 | 靠背景色块和线条粗细：观猹段白底粗线，TokenDance 段深底亮线，猹与猹段黑底细线。V03 的网点可以只给 TokenDance 段用，制造"机器感" |
| 推荐度 | ★★★☆☆。如果 10/13 甲方明确要求"必须像官方平面形象"，这是唯一答案；那样制作方式要改成"静帧为主、动作靠剪辑和镜头运动"，分镜里真正生成动态的镜头要压到 15 个以内 |

### 一个折中：V09 圆润哑光 3D 作为 A 和 C 之间的桥

V09 的角色比 V13 更"软"、更像表情包，背景又有基本的场景感（绿色办公室、展示台）。如果觉得 V13 太空、V05 太满，V09 是中间值。它的问题是原图里猹妹的马尾更长、猹猹的 T 恤更亮，需要按锚定图校准。

### 比较总表

| | A 干净 3D | B 漫画电影 3D | C 官方平面 |
| --- | --- | --- | --- |
| 4 天做完 62 镜的可行性 | 高 | 低 | 中（需改静帧为主） |
| 官方 IP 还原 | 中高 | 中 | 高 |
| 文字叠加 | 好 | 差 | 好 |
| 大场面表现 | 中 | 高 | 低 |
| 角色动态一致性 | 高 | 中 | 低 |
| 单帧好看程度 | 中 | 高 | 中 |
| 建议用途 | 全片主风格 | 海报、开场定场图 | 甲方坚持平面时的全片方案 |

### 如果要做跨场景测试（确认前的最后一步）

每个方向各生成同一组 4 张：1-1 敲镜头、3-4 空心瓜、6-3 工厂城、11-8 商务猹摘墨镜。四张放一排看：角色是不是同一个、文字放得下不、三段的气质分得开不。比单张好看更重要的是这四张像不像一部片子。

## 二、色彩脚本（r8 十二段）

色值是提案，正式使用前要从 `资产/品牌标识/` 的两个透明标识和猹与猹海报上取色校准。

建议的基础色板：

| 名称 | 建议值 | 用途 |
| --- | --- | --- |
| 观猹绿 | 取自观猹标识 | 信息卡底、观猹段主色 |
| 瓜田深绿 | 比观猹绿深两档 | 瓜叶、田垄 |
| 奶白 | 略带暖的白 | 观猹段天空和留白、猹猹身体 |
| 瓜红 | 饱和的西瓜红 | 只在 02、03、12 出现 |
| 墨黑 | 近黑的深灰 | TokenDance 段底色、猹与猹段底色 |
| 青绿霓虹 | 亮的青绿 | TokenDance 段 Token 光点、线路亮起 |
| 海报绿 | 取自猹与猹绿底海报 | 猹与猹段点缀 |
| 熊耳棕 | 取自猹妹锚定图 | 猹妹帽子和衣服，全片唯一的暖棕 |

| 段 | 底色 | 光 | 点缀色 | 情绪 | 构图关键词 | 避免 |
| --- | --- | --- | --- | --- | --- | --- |
| 01 敲镜头 | 虚焦的瓜叶绿 | 白天顶光，柔 | 猹猹的白、绿 T 恤 | 好奇、亲近 | 固定机位、脸贴镜头、鼻印 | 背景出现任何文字；镜头畸变过强 |
| 02 瓜田 | 奶白天空加瓜田深绿 | 上午斜阳，暖 | 瓜红、产品名牌的白 | 轻快、有梗 | 后拉升高的大全景、标题立在田中央、气泡叶 | 瓜红面积过大；田垄太整齐像农田广告 |
| 03 品鉴大会 | 暗场加一束追光 | 追光硬、周围暗 | 评委席木色、分数牌白、礼花多彩 | 综艺、紧张后释放 | 追光圆、对称评委席、传送带斜入 | 追光把角色脸打平；礼花颜色超过三种 |
| 04 用起来 | 浅灰的界面底、工作室米色 | 屏幕冷光加室内暖光 | 观猹绿按钮、爱猹收绿模块、收款通知的绿 | 顺畅、小确幸 | 屏幕占画面一半、绕到界面背后的"舞台布景"结构 | 界面细节过多；注册纸卷颜色抢戏 |
| 05 产品背后 | 工作室变暗、屏幕变亮 | 屏幕冷光为主 | 便利贴的黄、线缆的灰 | 忙乱、好奇 | 便利贴贴满、线缆缠身、屏幕像水面 | 线缆太多看不清角色 |
| 06 模型工厂 | 墨黑 | 先是全黑只有 T 发光，D 拼上后青绿霓虹亮起 | 青绿霓虹、Token 光点的淡金 | 安静到爆发 | 大厅对称、DJ 台居中、工厂城放射状管道 | 蓝紫色赛博味；霓虹颜色超过两种；地面反光 |
| 07 面向企业 | 墨黑加深灰的调度室 | 大屏冷光 | 线路图的青绿、拥堵线路的暗红、指标变绿 | 冷静、有序 | 线路图占大屏、D 在线路上跳、猹猹指挥棒在前景 | 红色用太多；像股票大屏 |
| 08 面向开发者 | 墨黑加体验台的浅灰 | 体验台顶光 | TokenPay 钱包的青绿、收益曲线的绿 | 轻松、成长 | 钱包、模型、应用三点连线的图示化构图 | 钱包画成金融产品；曲线画成股价 |
| 09 面向品牌 | 墨黑渐渐变暖 | 卡片自带光 | 联名卡的淡金、插画的多彩 | 玩笑、惊喜 | 卡从上方落下的仰拍、平板居中 | 卡做成信用卡金属感；吉祥物撞色 |
| 10 直升机 | 深夜冷蓝灰、舱内暗绿 | 博主房间只有屏幕光；舱内仪表绿光；城市夜景点光 | 探照灯白、仪表绿、猹与猹楼顶标识绿 | 低落、然后被接住 | 博主趴桌的俯拍、舱内对坐、航拍推向大楼 | 房间太脏乱；舱内太暗看不清角色 |
| 11 猹与猹 | 黑 | 顶光硬、轮廓光绿 | 海报绿、墨镜反光、交流空间转暖白 | 专业、有气场、最后温暖 | 对称、长桌俯拍、五张卡扇形、摘墨镜正面特写 | 任何金色或红色；办公室太写实 |
| 12 回到瓜田 | 奶白加瓜田绿 | 清晨逆光，暖 | 瓜红、三个标识各自的颜色 | 松弛、圆满 | 绳梯滑下、大家围坐、升到俯瞰出标识 | 三个标识颜色互相打架；定版背景太花 |

三段的色温曲线：02–05 暖 → 06–09 冷 → 10 最冷 → 11 由冷转暖 → 12 最暖。观众不看字幕也能感觉到"走了一圈回家"。

## 三、字幕、信息卡、整屏大字的三套样式候选

字幕有硬约束，三套都一样：底部安全区、单行不超过 16 个汉字、无衉线字体、白字黑描边、全片字号和位置统一（brief 要求，位置参考影视飓风的截图）。三套的差别在信息卡和大字。

### 方案甲｜保守：像纪录片的注释

| 元素 | 规范 |
| --- | --- |
| 字幕 | 思源黑体或苹方 Medium；1080p 下字高约 44 px；纯白加 2 px 黑描边再加轻微投影；底边距 90 px；淡入淡出各 4 帧 |
| 信息卡 | 白底、左侧一条观猹绿竖线、深灰字；出现在被说明物体的右上方或画面左上区；从左向右展开 6 帧，停留到旁白讲完下一句，再淡出；一屏只有一张 |
| 整屏大字 | 思源黑体 Heavy；字高占画面 25%；白字，背景压暗 30%；每字一拍弹入，轻微过冲；全片 5 次 |
| 适合 | 甲方偏严肃、要求"像正规企业宣传片"时 |

### 方案乙｜品牌感强：绿标签系统

| 元素 | 规范 |
| --- | --- |
| 字幕 | 同上；描边改为深绿黑（接近黑但带一点观猹绿），和全片色板统一 |
| 信息卡 | 观猹绿底、白字、圆角 12 px；左侧一个小图标（对应内容：评分、登录、钱包、卡片等）；TokenDance 段底色改为青绿霓虹加墨黑字，猹与猹段改为海报绿；出现时从物体位置"弹"出来，带一条细线指向物体，收起时缩回物体；一屏一张 |
| 整屏大字 | 粗黑体；观猹段白字，TokenDance 段青绿字加发光描边，猹与猹段白字加绿轮廓光；每字随重拍砸下，落地时画面轻震 2 帧 |
| 适合 | 这是我推荐的默认方案：观众看两次就知道"绿标签 = 事实"，三段换色又能和色彩脚本对上 |

### 方案丙｜综艺感强：花字

| 元素 | 规范 |
| --- | --- |
| 字幕 | 同上；允许在笑点处把字幕里的一个词变色（例如"先用，再打分"的"先用"变绿） |
| 信息卡 | 像综艺花字：圆润字体、彩色描边、带小感叹号或小图标；位置跟着角色，可以歪一点；出现时"啪"地盖章式放大再回弹；允许同屏两张（一张事实、一张吐槽） |
| 整屏大字 | 超粗圆体；多色描边；带音效同步的抖动；允许用在"颠覆行业"这种反讽处 |
| 适合 | 如果 10/13 甲方说"再有趣一点"，用这套；风险是 TokenDance 的企业段会显得不正经，可以只在 02、03、09、10 用花字，07、08 用方案乙 |

三套都要遵守的规则：信息卡不进字幕安全区；信息卡的文字不和当前字幕重复；界面截图里的文字不算信息卡，但界面上要有一处高亮指示旁白正在讲的栏目。

## 四、开工前要先做的视觉资产（按优先级）

P0 是画风确认当天就要出的，没有它们一个镜头都生成不稳；P1 是开工第一天要有的；P2 可以边做边补。

### P0｜角色基础

| 资产 | 内容 | 为什么先做 |
| --- | --- | --- |
| 猹猹三视图加表情表 | 正、侧、背三视图；表情：好奇、兴奋（星星眼）、面无表情、心虚、惊讶、得意；道具手：举牌、抱瓜、拿指挥棒 | 全片 59 个镜头里他出现在 50 个以上 |
| 猹妹全身设定加三视图 | 官方只有上半身；需要定下半身：建议熊耳帽连体的棕色短款上衣加同色短裤或裙裤、短圆腿、小圆脚，保持"矮圆"比例和猹猹一致；表情：淡定、眯眼、满意、无语 | 她全片有大量全身动作（拽、按牌子、切瓜、拎钱包） |
| D 的造型 | 以 `资产/品牌标识/TokenDance-词元跳动-透明标识.png` 里的 D 为准：黑色几何体、内侧两道斜线当眼睛；姿势表：站立、起跳拉长、落地压扁、歪头、点头；材质哑光黑 | 06、07、12 三段的主角，拟人动画需要 TokenDance 同意，造型先出好拿去确认 |
| 三个标识的用法 | 观猹、TokenDance、猹与猹标识在浅底和深底上的两种版本；田垄版（12-3）的简化轮廓 | 02、06、11、12 都要落标识 |
| "周一不慌"图标 | 一个打勾的日历；需要在产品卡、产品页、体验台、站点路线上反复出现 | 贯穿物，名字待定但图标可以先做 |

### P1｜场景定场图（每个场景一张，确认后再出动态）

| 场景 | 用于镜号 | 要点 |
| --- | --- | --- |
| 瓜田白天大全景 | 2-3、2-4 | 瓜挂名牌、气泡叶子、田中央留标识位置 |
| 品鉴台 | 3-1 到 3-5 | 追光、评委席、传送带入画方向 |
