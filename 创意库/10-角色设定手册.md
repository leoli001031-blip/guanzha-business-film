# 角色设定手册

这是什么：观猹业务漫剧里所有会动的角色，每个一节，写清它是谁、怎么动、能做什么不能做什么、在 r8 每一段里干什么。
怎么用：写分镜和出图时查"动作习惯"和"不能做的事"；画风确认后，把"画风上要注意"一节交给出图的人。标注"脚本新增"的都不是官方设定，甲方不认可就撤。

官方依据：猹和猹妹的 IP 形象锚定图（资产/角色）、猹与猹的立体西装猹参考和两张海报（资产/猹与猹）、TokenDance 透明标识（资产/品牌标识）。官方表情库只有猹的五个：吃西瓜、惊讶、背西瓜、兴奋、疑惑，另有三个细节小表情：皱眉、害羞、委屈。猹妹只有上半身。

---

## 1. 猹猹

**一句话定位：** 嘴馋、好奇、手比脑子快的普通用户，全片"第一次用的那个人"。

**性格三个词：** 好奇、冲动、心虚得快。

**代表谁：** 台下每一个第一次打开新 AI 产品的人。他犯的错都是观众犯过的错。

**动作习惯（可直接画）：**
1. 鼻子先到。看什么都先把脸凑过去，鼻子压扁（1-1）。
2. 东西往身后藏。心虚的标准动作：瓜、注册纸卷、大耳机都这么藏（2-1、4-2）。
3. 抬手就举 10 分。看到闪的就冲动，然后被一根手指按下去（3-3）。
4. 手比脑子快。戳屏幕、搓碟、抄指挥棒，先动手再想（5-2、6-6、7-2）。
5. 学别人，总学歪。学商务猹挺腰，耳机滑下来；学摘墨镜，摘下的是耳机（10-5、11-9）。
6. 尾巴出卖情绪。炸毛是受惊，耷拉是泄气，左右摇是得意。
7. 拿到不认识的东西先闻一闻（9-2）。

**表情对应官方表情库：**

| 情境 | 用哪个 |
| --- | --- |
| 看到大瓜、举 10 分、第一个作品做出来 | 兴奋 |
| 钢叉、被旁白吓到、栽进屏幕 | 惊讶 |
| 找旁白的声音从哪来、看 D、看一堆 API Key | 疑惑 |
| 开场抱瓜跑 | 背西瓜 |
| 开场、结尾 | 吃西瓜 |
| 空心瓜给 3 分 | 细节小表情：委屈 |
| 被猹妹按下牌子 | 细节小表情：害羞 |
| 被线缆缠住、被瓜埋住 | 细节小表情：皱眉 |

**口头短句和反应音：** 吸鼻子、"嘿"、"哇"、倒吸一口气、走调的口哨、咬东西的"咔"。不说完整句子。

**能做的事：** 全身动作（官方有全身设定）；跑、跳、滑绳梯、栽进屏幕。
**不能做的事：** 说长句；戴官方没有的固定配饰（耳机、"墨镜"都是临时道具，用完要摘）；中段吃瓜（瓜只在 01–03 和 12）；表现出"懂行"，懂行是猹妹的。

**和其他角色的关系：** 猹妹是他的刹车；开发者猹是他用的产品的作者，他留言"按钮太小"；商务猹是他想模仿的人；D 是他第一个挥手打招呼的对象；旁白是逗他的人，也是唯一能让他立正的声音。

**在 r8 每段的功能：**

| 段 | 他在干什么 | 带出什么 |
| --- | --- | --- |
| 01 | 敲镜头，被旁白吓到 | 开场抓注意力 |
| 02 | 藏瓜、被钢叉追 | 猹偷瓜的典故 |
| 03 | 冲动举 10 分，被按下；拍空心瓜 | 先用再评 |
| 04 | 掏注册纸卷，卷回去 | 反复注册的麻烦 |
| 05 | 戳屏幕栽进去 | 转到模型能力 |
| 06 | 和 D 挥手、搓碟 | TokenDance 的节奏感 |
| 07 | 抄指挥棒，放下 | 系统自己会调度 |
| 08 | 留言"按钮太小"，点赞 v2 | 真实调用、快速验证 |
| 09 | 咬卡、画火柴人 | 用户用卡做出东西 |
| 10 | 戴大耳机挺腰，耳机滑下 | 商务猹的反衬 |
| 11 | 做出第一个小作品，摘"墨镜" | 一起学习成长 |
| 12 | 躺进瓜堆吃瓜 | 回家 |

**画风上要注意：** 头身比按锚定图，身体是一个圆润的梨形；绿 T 恤是唯一服饰，领口和下摆的黑线要保留；尾巴上两道纹路；小圆手没有手指；鼻子是黑色小圆点；不要加眉毛、牙齿、睫毛；白色身体在浅色背景上要靠描边或轮廓光分离。

## 2. 猹妹

**一句话定位：** 懂行、淡定、有点小腹黑的老用户，全片"把事情做对的那个人"。

**性格三个词：** 精明、淡定、暗地里心软。

**代表谁：** 台下已经用了很久 AI、知道怎么挑产品的人。她从不解释，只是做对。

**动作习惯（可直接画）：**
1. 一根手指。按下猹猹的牌子、点"观猹登录"、点"授权"，都是一根手指轻轻一点（3-4、4-1、8-3）。
2. 眯眼凑近镜头，像在读观众的心思（2-1）。
3. 收拾残局：擦鼻印、把猹猹拽开、把卡从他嘴里抽出来（1-2、9-3）。
4. 拎：拎钱包、拎钥匙、拎猹猹的尾巴（5-2、6-4、8-1）。
5. 只点一下头。满意时不欢呼，点一下（9-5）；忍不住的时候，点头点出节拍（6-6）。
6. 好东西到她手里先递给猹猹（9-1）。

**表情对应：** 官方只给了微笑嘴和小圆眼的基础脸。眯眼用小圆眼压扁表现；惊讶时眼睛变成更大的圆点、嘴张成小 o；腮红在被夸或害羞时加深。她的表情幅度始终比猹猹小一半，这是两人的区别。

**口头短句和反应音：** 轻哼"嗯"、阻止猹猹的"诶"、叹气、配合点击的"叮"。不说长句。

**能做的事：** 半身构图内的一切动作；坐在桌后、站在台前；手部特写。
**不能做的事：** 全身设定出来之前，不做跑、跳、滑绳梯这类全身大动作，12-1 滑绳梯要么等设定，要么只拍猹猹滑、她已经在地上；不说长句；不戴耳机以外的道具（10 的大耳机是临时道具）。

**和其他角色的关系：** 猹猹的刹车和搭档，她的"诶"比旁白的"诶"更早；对 D 是第一个敢动手的（插钥匙）；对开发者猹是第一个授权用户；对商务猹点头之交；对旁白像同事，旁白逗猹猹时她在旁边看戏。

**在 r8 每段的功能：**

| 段 | 她在干什么 | 带出什么 |
| --- | --- | --- |
| 01 | 把猹猹拽开，擦鼻印 | 谁管事 |
| 02 | 眯眼读观众心思 | 和观众建立关系 |
| 03 | 按下牌子，点开产品卡试用，抢邀请码 | 先用再评、邀请码 |
| 04 | 一根手指登录三个产品 | 观猹登录 |
| 05 | 抓尾巴，被一起拽进去 | 转场 |
| 06 | 从乱麻里抽出钥匙插进 DJ 台 | 一个 API Key |
| 07 | 看总屏 | 统一管理 |
| 08 | 拎 TokenPay 钱包，点授权 | 用自己的额度 |
| 09 | 接卡、递卡、从嘴里抽卡、贴平板 | 实体卡的用法 |
| 10 | 戴大耳机，一本正经 | 反衬 |
| 11 | 把猹猹按到空位上 | 一起学习 |
| 12 | 切瓜递瓜 | 回家 |

**画风上要注意：** 熊耳朵长在帽子上，不是头上；刘海加两侧头发，发色棕；腮红是两团，不是一道；头身比和猹一致，不要画成人类少女比例；帽子的棕色是全片第三种主色（绿、白之后），注意和猹与猹段的黑绿不打架。

## 3. 旁白

**一句话定位：** 熟悉 AI 圈、爱逗这两只的主持人，观众在片子里的代言人。她也是角色。

**性格三个词：** 成熟、年轻、带逗弄感（用户原话）。

**代表谁：** 观众自己。她替观众问问题，替观众吐槽，替观众说"诶"。

**"动作"习惯（声音上的）：**
1. 卖关子停顿："……嗯，猜对了。"
2. 一句话打断："诶，先用，再打分。"
3. 对观众说"你"："你是不是想问""如果你是开发者"。
4. 讲业务像给朋友推荐，不像念稿；术语留给屏幕。
5. 笑点处让位，停一拍再说。
6. 被角色听见的那几句，语气像在现场，离话筒更近、更轻。

**语气对应：** 开场逗弄；提问时真诚好奇；讲业务时从容；直升机段压低；结尾郑重但不煽情。

**口头短句：** 嗨，你好呀 / 诶 / 那个，不能吃 / 别问它们怎么上来的 / 嗯，猜对了。

**能做的事：** 介入角色动作；对观众说话；念甲方的品牌定位句。
**不能做的事：** 念宣传册（07–09 的术语在屏幕上）；抢笑点（角色动作时她停）；扮演别人的声音（商务猹、无线电是另外的声音）；评价业务（"真不错"这类禁用）；用网络梗。

**和其他角色的关系：** 对猹猹像姐姐对弟弟；对猹妹像同事；对商务猹保持距离，规则那句让他自己说；对 D 只在拼图那句上配合它的动作。

**在 r8 每段的功能：**

| 段 | 她在干什么 |
| --- | --- |
| 01 | 吓猹猹一跳，介绍两位 |
| 02 | 卖关子，讲典故，讲观猹定位 |
| 03 | 提问，打断猹猹，点名六个栏目 |
| 04 | 讲登录和收款 |
| 05 | 承上启下 |
| 06 | 说"拼图"，报品牌名，念六种能力和四个字 |
| 07–09 | 用人话讲三个"如果你是" |
| 10 | 压低声音，说"别问它们怎么上来的"，然后让位给无线电 |
| 11 | 讲公司和五项服务；规则卡出现时沉默 |
| 12 | 三句结语 |

**声音上要注意：** 以配音方向调研里的 A 方向（松弛的 AI 搭子）为起点；试听时重点听她讲"API Key""TokenPay"时还像不像同一个人；互动句和讲述句是同一个人，只是互动句更近更轻。

## 4. 开发者猹

**一句话定位：** 做出"周一不慌"的个人开发者，全片唯一有完整弧线的角色：做出产品，收到钱，接上模型，被看见。

**性格三个词：** 踏实、闷头干、小小得意。

**代表谁：** 台下的独立开发者和小团队。

**外观：** 猹的造型加一副细黑框圆眼镜。眼镜是脚本新增的区分物。前稿写过"灰卫衣"，属于官方没有的服饰，建议不用，保留绿 T 恤，靠眼镜和笔记本电脑区分；画风确认后甲方同意再考虑换装。

**动作习惯（可直接画）：**
1. 推眼镜，紧张或思考时。
2. 偷偷握拳，收到第一笔钱（4-4）。
3. 额头冒汗，然后汗珠倒着缩回去（8-4）。
4. 改几行代码的手速，画面只看手。
5. 被线缆缠住还在打字（5-1）。
6. 抱着电脑走路（12-2）。

**表情对应：** 兴奋是第一笔收入；疑惑是面对一堆 Key；惊讶是猹猹栽进他的屏幕；皱眉是被线缆缠住。

**反应音：** 键盘声、松气的"呼"、小声的"耶"。

**能做的事：** 说一两个词；做正常人的动作。他是"正常"的参照物，猹猹才是夸张的那个。
**不能做的事：** 夸张动作；出现在企业段（07）和猹与猹段（10、11）；在 03 以前露脸。

**和其他角色的关系：** 猹猹是他的用户；猹妹是他的第一个授权用户；他的产品是全片的贯穿物；结尾和博主猹、商务猹同坐，说明三块业务服务的是同一群人。

**在 r8 每段的功能：**

| 段 | 他在干什么 | 带出什么 |
| --- | --- | --- |
| 03 | 他的产品"周一不慌"拿两个 10 分（本人不露面） | 好产品 |
| 04 | 接上爱猹收，第一笔收入 | 个人开发者收款 |
| 05 | 被一堆 API Key 和账单缠住 | 需要模型聚合 |
| 06 | 他的 Key 乱麻飘进工厂（本人不在） | 一个 API Key |
| 08 | 站在体验台旁，改 v1 到 v2，收益上涨 | TokenPay |
| 10 | 他的产品跑起来、爬榜（分屏） | 跑起来、被看见 |
| 12 | 抱着电脑来吃瓜 | 闭环 |

**画风上要注意：** 眼镜是细线、圆形，不遮小圆眼；不要给他加胡子、领带这类"程序员刻板"元素；电脑上贴一个"周一不慌"的图标。

## 5. 博主猹

**一句话定位：** 内容很好、商务很差的 AI 博主，猹与猹的"目标"。

**性格三个词：** 有才、熬夜、不会谈钱。

**代表谁：** 台下的 AI 博主和创作者，猹与猹想招的人。

**外观：** 猹的造型加一副头戴式耳机（道具，可挂在脖子上）。

**动作习惯（可直接画）：**
1. 耳机挂脖子上，讲话时才戴上。
2. 对着报价单发愣。
3. 趴在键盘上睡着（10-2）。
4. 竖大拇指，照官方"单猹点赞"的姿势（11-6）。
5. 分享屏幕时手舞足蹈。
6. 手机亮了，先看一眼，再笑。

**表情对应：** 兴奋是在"创作者说"里讲产品；委屈是深夜面对账单；害羞是被夸；点赞用官方立体参考的站姿。

**反应音：** 打哈欠、看到私信的"诶？"、笑。

**能做的事：** 在 03 露一次脸（创作者说），10–12 出场。
**不能做的事：** 在 03 以前出现；做商务动作（那是商务猹的）；说完整句子。

**和其他角色的关系：** 商务猹接手他；开发者猹和他在结尾同坐；猹猹在交流空间学他做作品；他讲的那款产品就是"周一不慌"，让 03 和 10 连起来。

**在 r8 每段的功能：**

| 段 | 他在干什么 | 带出什么 |
| --- | --- | --- |
| 03 | 在"创作者说"里讲周一不慌 | 创作者说 |
| 10 | 深夜被私信和报价单埋住，睡着 | 内容好，商务卡住 |
| 11 | 档案落桌；收到回款，点赞；分享屏幕 | 五项服务、回款、一起学习 |
| 12 | 摘下耳机坐下吃瓜 | 闭环 |

**画风上要注意：** 耳机是唯一区分物，颜色用猹与猹的黑；深夜场景用冷色，但他的白色身体要保持干净，不要脏。

## 6. 商务猹（领头的一只，以及小队）

**一句话定位：** 话少、气场大、永远先到一步的经纪人，猹与猹公司的化身。

**性格三个词：** 沉稳、利落、有一点点反差萌。

**代表谁：** 猹与猹公司本身；在台下想签约的博主眼里，是"靠谱的人"。

**外观：** 黑西装、白衬衫、黑领带，按官方立体参考。墨镜和耳麦是脚本新增，摘墨镜是全片唯一一次露出他的小圆眼。小队成员和领头的一模一样，只有领头的戴耳麦。

**动作习惯（可直接画）：**
1. 按耳麦（10-4）。
2. 单手接住飞回来的卡（11-4）。
3. 摘墨镜，全片只一次（11-8）。
4. 松领带，只在结尾（12-2）。
5. 对称站位，同时起身（10-6、11-2）。
6. 帮猹猹扶正东西，反差（11-9）。

**表情对应：** 戴墨镜时只剩嘴，所以嘴型是他唯一的表情：抿嘴是严肃，微笑是说规则那句。摘墨镜后用官方立体参考的微笑脸。

**台词：** 全片只有两句，"收到，接手。"和甲方原句"你专心做内容，商业的事，猹与猹来。"声音低沉克制，舱内那句带耳麦和无线电处理。

**能做的事：** 说完整句子（全片唯一）；慢动作；对称构图。
**不能做的事：** 笑场、跑、惊讶；小队成员说话；出现"华与华"式的具体标识、配色、口号。

**和其他角色的关系：** 对博主是接手者；对猹猹是被模仿的对象，也会伸手帮他；对猹妹点头之交；对开发者无交集，结尾同坐。

**在 r8 每段的功能：**

| 段 | 他在干什么 | 带出什么 |
| --- | --- | --- |
| 10 | 舱内按耳麦，应答"收到，接手"；楼顶并肩站 | 猹与猹出现 |
| 11 | 小队起身，甩开五张卡，接住；摘墨镜说规则 | MCN、五项服务、规则 |
| 12 | 松领带来吃瓜 | 商务猹也是猹 |

**画风上要注意：** 官方参考有黑西装和灰西装两版，选黑；西装要显出布料的哑光，不要油亮；墨镜在深色场景里要有一道反光才看得出是墨镜；三只以上时用同一模型复制，站位严格对称。

## 7. D

**一句话定位：** TokenDance 标识里的 D，不说话的小角色，整座模型工厂的开关。

**性格三个词：** 好奇、有礼貌、爱蹦。

**代表谁：** TokenDance 本身。它一来，什么都通了。

**外观：** 标识里的 D 原样，黑色，内侧两道斜线当眼睛。不加手脚，不加嘴，不加眉毛。

**动作习惯（可直接画）：**
1. 一跳一停。落地挤扁、弹起拉长，幅度不超过 15%，多了就不像标识了。
2. 歪头，是看、是听。
3. 点头，是同意。
4. 跳到哪里，哪里亮。
5. 回家：拼回 T 旁边，"咔"一声合上。
6. 轻跳一下，是打招呼（12-3）。

**表情：** 只有两道斜线的角度和间距。平行是平静，上扬是高兴，一高一低是好奇，靠近是专注。

**反应音：** 落地"咚"、拼上"咔"、溅起光点的"叮"。不发人声。

**能做的事：** 被猹妹插钥匙（它不介意）；领路；在厂区之间跳。
**不能做的事：** 说话；变成别的字母或形状；离开 TokenDance 段，只在 06、07 和 12-3 出现；碰瓜。标识的拟人化需要品牌方同意，见分镜待确认。

**和其他角色的关系：** 对猹猹，是第一个和他挥手的朋友；对猹妹，她敢对它动手；对工厂，是开关；对 T，是回家。

**在 r8 每段的功能：**

| 段 | 它在干什么 | 带出什么 |
| --- | --- | --- |
| 06 | 跳进来，拼上 T，点亮六个厂区，跳回标识 | 拼图、六种能力 |
| 07 | 先试拥堵线路，再跳到最顺的，请求跟着它走 | 智能路由、择优 |
| 12 | 标识里轻跳一下 | 品牌回收 |

**画风上要注意：** 黑色哑光，自身不发光，落地时溅光点；深色底上要有一圈细描边或轮廓光才看得见；挤扁拉长时字形的粗细要保持，不能变成气球。

## 8. 群演

**瓜田里的猹：** 同一个模型，三种姿势复制就够：蹲着吃瓜、两只凑在一起聊、给瓜贴评分贴纸。不换服饰，远景不画表情。

**交流空间的博主们：** 猹的造型，用道具区分：耳机、平板、画笔、相机，最多五只。有人讲、有人上手试、有人举手。

**联名品牌吉祥物（9-5）：** 虚构，单色，轮廓和猹明显不同（方块或水滴形），比猹小一号，只做一个动作：从画里探出来击掌。有真实联名方时整个替换。

**品牌方（11-4 握手）：** 只露一只手或一个剪影，不建新角色。

**钢叉：** 只露叉头，不出现闰土，不出现人。

**请求小方块（07）：** 同色小方块，排队、打哈欠、跟着 D 走，是 07 唯一的"群演"。
