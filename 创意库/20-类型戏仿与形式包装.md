# 创意库 20｜类型戏仿与形式包装

这份文件是什么：16 种把整部片子套进去的"类型片 / 节目形式"外衣。01 号讲的是结构（段落顺序），04–06 讲的是单段比喻，这里讲的是全片的"气质和节奏签名"，三者可以组合：例如 01-4 倒叙 + 本文 9 侦探 + 05-1 总闸。

怎么用：先看"节奏签名"和末尾对照表，挑 2–3 种再读"怎么做"。每种都写了猹猹、猹妹、商务猹、D 在这个形式里的身份，以及 30 秒示范。所有示范里的旁白都保留甲方原文信息，术语照旧放画面。第一轮已有的形式只给一句指路，不重复：发布会 keynote 见 01 号第 5 条，弹幕问答见 01 号第 6 条，综艺闯关见 01 号第 7 条，测评直播间（单段）见 04 号第 3 条，相亲角见 04 号第 4 条，试吃街见 04 号第 5 条。

标签：#瓜 #无瓜 #零时长 #需甲方素材 #高制作成本 #低制作成本 #更逗 #更正式 #我推荐 #突破约束。打了 #突破约束 的，在"代价"里写了突破什么。

### 1｜相声对口：旁白逗哏，画外捧哏

一句话：女旁白是逗哏，再加一个男声捧哏，猹猹猹妹在画面里演"包袱"；三块业务是三段贯口。
节奏签名：一逗一捧的乒乓节奏，每 3–5 秒一个"诶？""那可不"；到清单处突然加速成贯口，收尾一个"好！"。
适合：观众是中文互联网的熟人，现场气氛松；主办方接受喜剧质感。
怎么做：
- 观猹：逗哏讲猹的来历，捧哏接"那不是偷瓜的吗"；六个栏目是第一段贯口。
- TokenDance：贯口报六种能力、三个面向；捧哏在"全、快、稳、省"后喊"好！"；D 是道具包袱："这是什么？""D。""D 是什么？""词元跳动的 D。"
- 猹与猹：捧哏装不信"二百五十多位？"逗哏："截至九月。"规则那句由商务猹说，两人齐声"哦——"。
- 角色身份：猹猹 = 包袱的肉身，专门演砸的那个；猹妹 = 收拾局面的；商务猹 = 唯一开口的嘉宾；D = 道具。

| 秒数 | 画面 | 旁白或台词 | 声音 |
| --- | --- | --- | --- |
| 0–3 | 传送带送瓜堆成山，两只被埋 | 逗：AI 产品太多了。捧：多到什么程度？ | 综艺鼓点 |
| 3–6 | 产品卡不停 +1 | 逗：新工具、新模型、新应用，天天冒。捧：那怎么挑？ | 传送带声 |
| 6–9 | 大瓜登场，猹猹举 10 | 逗：诶，先用，再打分。捧：对，别看包装。 | 闪光"叮" |
| 9–12 | 拍大瓜，空心 | 捧：空的？逗：功能开发中，敬请期待。 | "嘭" |
| 12–15 | 小瓜出周报，双 10 分 | 逗：这个，一键出周报。捧：十分！ | "啪"，礼花 |
| 15–24 | 产品页六栏目弹出 | 逗（贯口）：在观猹，评分、讨论、榜单、创作者说、邀请码、真实案例。捧：好！ | 六声"嘣" |
| 24–30 | 产品页化进社区 | 逗：它不是信息流，也不是产品库。捧：那是什么？逗：围绕真实体验的社区。 | 音乐扬起 |

信息落点：甲方原文全部可进逗哏台词；捧哏只接话不带新信息；术语照 r8 放画面。
代价：多一个男声配音（可从配音调研的 A1、B2 方向试）；捧逗的气口 TTS 做不好，最好真人；时长比 r8 多 5–10%，要靠捧哏接话短；和官方 IP 相容高，画面不用改。
和 r8 的关系：画面完全沿用，只换音轨；最便宜的"换气质"方案。
标签：#低制作成本 #更逗 #我推荐

### 2｜伪纪录片采访：当事人对镜头说

一句话：三块业务由"当事人"对镜采访带出，中间插"实拍"；猹猹的采访靠字幕翻译它的动作。
节奏签名：采访（静、对镜、固定机位）和实拍（动、轻微手持）交替，每 8–12 秒切一次；笑点全在"采访里说的"和"实拍里发生的"对不上。
适合：观众看过办公室喜剧；想要"真实观察"的气质和观猹定位呼应。
怎么做：
- 观猹：采访猹猹"你怎么挑 AI 产品？"它比划拍瓜，字幕翻译"先用，再打分"；切实拍品鉴，它正要给大瓜举 10。
- TokenDance：采访开发者猹，它指着满屏 API Key 的便利贴叹气，字幕"以前要接六个"；切实拍它掉进工厂、猹妹插钥匙。
- 猹与猹：采访商务猹，这是全片唯一真开口的采访，三句回答就是原文；采访博主猹，手机举给镜头"回款到账"。
- 角色身份：猹猹 = 嘴硬的受访者；猹妹 = 镜头后面偶尔入画纠正的人；商务猹 = 唯一能说话的受访者；D = 在采访背景里跳过去的"路人"。

| 秒数 | 画面 | 旁白或台词 | 声音 |
| --- | --- | --- | --- |
| 0–4 | 采访机位，商务猹摘墨镜坐下 | 商务猹：猹与猹，观猹旗下的创作者商业化公司。 | 房间底噪 |
| 4–8 | 同机位 | 商务猹：一家从 AI 生态里长出来的 MCN。 | — |
| 8–14 | 实拍：长桌，五张任务卡扇开 | 旁白：对 AI 博主做经纪。商务对接、报价谈判、垫付回款、AI 工具链、IP 设计。 | 盖章声 ×5 |
| 14–17 | 采访：博主猹举手机"回款到账" | 字幕：（到账了。截至九月，和我一样的有二百五十多位。） | "叮" |
| 17–21 | 实拍：交流空间 | 旁白：一起学习、成长，消除做内容和学 AI 的信息差。 | 音乐转暖 |
| 21–25 | 采访：商务猹看镜头 | 商务猹：我们的规则只有一句话。 | 底噪 |
| 25–30 | 采访：猹猹抢镜，被猹妹拉走 | 商务猹：你专心做内容，商业的事，猹与猹来。 | — |

信息落点：全部原文；采访字幕承担角色"说"的部分，角色仍不发声。
代价：采访机位和实拍机位要统一两套光；采访字幕量大，和底部正式字幕要分层（采访字幕放中下方），需和甲方确认字幕规范；时长中性；相容高。
和 r8 的关系：结构不变，只在 03、08、11 三处插采访，其余保留。
标签：#低制作成本 #更逗

### 3｜新闻联播：主播猹妹，记者猹猹

一句话：猹妹坐主播台，猹猹是外景记者，三块业务是三条新闻，底部滚动条一直在输信息。
节奏签名：主播正襟播报（稳）和连线现场状况（乱）交替；每条新闻 40–60 秒；滚动条、角标、图表让屏幕任何时刻都有信息。
适合：要信息密度最高的形式；猹妹只有上半身设定，坐主播台正好只露上半身。
怎么做：
- 头条：主播念"我们是 AI 产品的大众点评，AI 时代的产品分发和内容社区平台"；记者连线品鉴大会，被瓜埋住；演播室图表出六个栏目。
- 第二条：标题"TokenDance：一个 API Key，连接国内主流模型"，图表出六种能力、三个面向；D 是演播室角标里跳出来的 logo。
- 第三条：记者在摩天楼前连线，商务猹接受采访说规则；主播播"截至九月，签约 AI 博主二百五十多位"。
- 结尾：天气预报位置改成"明日生态提示"，三句分工。
- 角色身份：猹妹 = 主播；猹猹 = 老出状况的外景记者；商务猹 = 受访嘉宾；D = 台标。

30 秒示范（第二条新闻开头）：

| 秒数 | 画面 | 旁白或台词 | 声音 |
| --- | --- | --- | --- |
| 0–4 | 主播台，猹妹，角标"生态快讯" | 主播：下面来看第二条。观猹生态的另一块拼图，TokenDance 词元跳动。 | 新闻垫乐 |
| 4–8 | 右上角 D 跳进台标，拼成 TD | 主播：观猹生态旗下的一站式大模型 API 聚合平台。 | "咔" |
| 8–12 | 演播室大屏：一把钥匙，六个厂区 | 主播：一个 API Key，连接国内主流模型。 | 图表音 |
| 12–18 | 大屏六个能力图标依次亮 | 主播：覆盖文本、图像、视频、语音、多模态、联网搜索。 | 六声"嘀" |
| 18–22 | 切记者猹猹在工厂里，被 Token 光点砸到 | 记者：（举话筒，被砸，字幕"现场信号中断"） | 杂音 |
| 22–26 | 主播尴尬一秒，图表接上 | 主播：全、快、稳、省。 | 四记重拍 |
| 26–30 | 滚动条出"面向企业 / 开发者 / 品牌与用户" | 主播：三类用户，三种用法，稍后详细报道。 | 垫乐 |

信息落点：原文全部可念；滚动条和图表可以把所有术语原样放上去，是信息承载最强的形式。
代价：主播台、图表、滚动条的动效制作量大，但都是模板化工作；更正式，笑点靠记者连线；时长中性；相容高，猹妹上半身是优势。
和 r8 的关系：画面要重做 60%（主播台、图表），实拍连线可复用 r8 的 03、06、10。
标签：#更正式 #我推荐 #无瓜

### 4｜天气预报：AI 行业今日气象

一句话：一期"AI 行业天气预报"：新品暴雨、算力晴好、商务回款多云转晴。
节奏签名：平稳播报配夸张的气象图标，每 10 秒换一张"气象图"；信息靠图标加数值。
适合：想要克制、好读、略带冷幽默；画面以图表为主、角色动作少的制作条件。
怎么做：
- 观猹："今日新品：局部暴雨，每天都有新工具、新模型、新应用"；"观猹气象台提供真实观察"，六个栏目是六个气象要素；观猹登录 = "一把伞走遍所有产品"；爱猹收 = "开发者收成预报"（示意）。
- TokenDance："算力供应：全、快、稳、省"，像电力预报；三个面向是三个地区的分区预报。
- 猹与猹："商务回款：多云转晴"，直升机是气象直升机，商务猹是出外勤的预报员。
- 角色身份：猹妹 = 气象主播；猹猹 = 被天气砸到的示范员；商务猹 = 外勤预报员；D = 气象图上跳动的高压中心。

| --- | --- | --- | --- |
| 0–4 | 气象图，雨云图标密集 | 各位观众，今日 AI 行业天气：新品暴雨。 | 预报垫乐 |
| 4–8 | 雨点变成产品卡砸下来，猹猹被埋 | 新工具、新模型、新应用，天天冒出来。 | 雨声变"嘀嘀" |

| 22–26 | "观猹"翻成"观察" | 观猹，也是观察。 | 翻牌 |

代价：比喻有硬伤处（收款、钱包），需要在屏幕上用原话兜住；图表为主，制作低；更正式；时长中性；相容高。
和 r8 的关系：整体换形式；r8 的直升机、D 可以保留。

### 5｜体育解说：一个产品的三个赛段

一句话：两个解说（一个激情、一个专业）解说"周一不慌"从发布到赚钱的比赛，三块业务是三个赛段。
节奏签名：解说语速随画面起伏，关键动作慢放加"精彩回放"字样，得分板常驻；每个赛段结束有一次"冲线"。
适合：现场观众多、大屏加音响好；想要热血而不是可爱。
怎么做：
- 第一赛段"被看见"：品鉴评委举牌 = 裁判亮分；六个栏目 = 赛事数据栏；观猹登录 = 一张通行证过所有检录口。
- 第二赛段"跑通能力"：TokenDance 是进站换胎，一个 API Key 一次换好六个轮胎（六种能力）；"全、快、稳、省"是圈速板上的四项；三个面向 = 三支车队的用法。
- 第三赛段"赚到钱"：猹与猹是教练席和经纪团队，250+ 是签约球员数；规则一句话是暂停时教练说的话。
- 角色身份：猹猹 = 赛场边乱入的吉祥物；猹妹 = 领队；商务猹 = 主教练；D = 发令员，一跳一个起跑枪。

30 秒示范（第二赛段）：

| 秒数 | 画面 | 旁白或台词 | 声音 |
| --- | --- | --- | --- |
| 0–3 | 产品"周一不慌"驶入维修区 | 激情：进站！进站！专业：它需要接模型能力。 | 引擎声 |
| 3–7 | 开发者猹手忙脚乱拿六把扳手 | 专业：以前要换六个轮胎，六个 Key。 | 扳手掉地 |
| 7–11 | 猹妹一把钥匙插下去，六个轮胎同时换好 | 激情：一个 API Key！专业：连接国内主流模型。 | "咔咔咔" |
| 11–17 | 六个轮胎上亮出能力图标 | 专业：文本、图像、视频、语音、多模态、联网搜索。 | 六声鼓点 |
| 17–21 | 圈速板四个字 | 激情：全！快！稳！省！ | 四记重拍 |
| 21–25 | 慢放回放，D 举起发令旗 | 专业：精彩回放，TokenDance 词元跳动，一站式大模型 API 聚合平台。 | 慢放音 |
| 25–30 | 出站，三个车队标志 | 激情：出站！专业：企业、开发者、品牌，三种用法，马上来看。 | 引擎轰鸣 |

信息落点：原文可念，由"专业解说"负责；"激情解说"只负责情绪。
代价：两个解说配音；慢放回放使时长多 10%；赛道场景要新做，但角色动作可少；相容高；现场效果最强之一。
和 r8 的关系：整体换外衣，r8 的品鉴、钥匙、D、直升机都能保留。
标签：#更逗 #高制作成本

### 6｜动物世界：解说猹的习性

一句话：用自然纪录片的口吻讲"猹"这种生物：觅食（挑产品）、觅能（模型工厂）、群居（社区）、迁徙（直升机）。
节奏签名：慢、长镜头、低沉解说，隔 20 秒一句干巴巴的冷幽默；信息以"习性陈述"的方式出现。
适合：想要反差冷幽默而不是热闹；接受全片节奏偏慢。
怎么做：
- 观猹："猹，栖息于瓜田，以吃瓜为生。观猹的猹则以 AI 产品为食。"六个栏目是"群体内的六种信息交换行为"；观猹登录 = "一个记号走遍领地"；爱猹收 = "个体开发者由此获得回报"。
- TokenDance："猹的能量来自地下的词元工厂……一个 API Key 连接国内主流模型。"D 是"工厂里的一种共生生物"。
- 猹与猹："成年猹中有一支穿西装的，专司商务。截至九月，已签约 AI 博主二百五十多位。"规则一句话由商务猹对镜头说，解说补一句"它们很少说话，一说就是这句"。
- 角色身份：猹猹 = 被观察的典型个体；猹妹 = 群体里的领头者；商务猹 = 西装亚种；D = 共生生物。
- 和 01 号第 2 条的区别：那条是跟拍一个产品 90 天的纪录片结构；这条是解说生物习性的口吻，结构可沿用 r8。
