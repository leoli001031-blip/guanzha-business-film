# 片名与标语候选

这份文件集中放"叫什么"和"怎么开口"的候选：片名、章节标题、结尾 slogan、每一段的第一句钩子、三个角色的口头短句。都是候选，没有定稿；带"甲方原句"或"海报原句"标注的可以直接用，其余是提案。

用法：片名和章节标题挑一套风格统一的；slogan 第 1 条是甲方定稿句，其余用于字卡、海报或社媒；钩子按段落替换 r8 的第一句试效果；角色短句给配音和动画参考。

## 五、角色口头短句（3 × 8）

猹猹和猹妹基本不说长句，只有反应音和短词；商务猹话少、句短。

### 猹猹

| 短句 | 用在什么情境 |
| --- | --- |
| 嗯？ | 1-1 听到旁白，左右找人 |
| 诶！ | 3-3 看到闪光大瓜，眼睛变星星 |
| 哇—— | 3-5 举 10 分、礼花炸开 |
| 嘿嘿 | 2-1 把瓜往身后藏，以为没人看见 |

| 嗯嗯！ | 8-4 对 v2 的大按钮点赞 |
| 吸溜 | 12 吃瓜，全片结尾 |
