视觉规范（提案）

三个色彩世界。 观众不看字幕也知道到了哪一块业务；结尾田垄上三个标识亮起，就是三种颜色回到同一块地里。

段落底色和光点缀
观猹（01–05、12）官方绿、白天暖光、浅色天空瓜红只出现在开场、品鉴和结尾

信息卡。 全片同一种样式：绿底白字的圆角标签，出现在物体旁或画面上半部，不进底部字幕安全区。一屏最多一张；信息卡的字不和字幕重复。观众看两次就会知道"绿标签 = 事实"。

大字。 整屏大字只用五次：观猹标题、一个 API Key、全快稳省、250+、规则一句话。每次配重拍。

界面。 观猹产品页、观猹登录、爱猹收、TokenPay 优先用真实界面录屏，否则按真实界面仿制；界面里的产品一律用虚构名。

字幕。 按 brief：底部安全区、单行不超过 16 个汉字、无衬线、白字黑描边、全片统一。

贯穿物。 "周一不慌"的图标（一个打勾的日历）；TokenDance 标识里的 D。

画风（建议，待风格对话确认）。 用干净 3D 系列（V13、V14、V16）做底，三段只用布光和配色区分，不换画风。理由：画面要叠字幕、信息卡和界面，干净的底不和文字打架；62 个镜头 4 天出，简洁 3D 的角色一致性最好；甲方给的猹与猹素材本身就是 3D 西装猹。和官方平面 IP 的差距，靠五官比例、绿 T 恤、熊耳帽一比一照搬来保。
